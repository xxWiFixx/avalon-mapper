# Проверка приватности распространяемых файлов

Сборка приложения включает только явно перечисленные каталоги и файлы рантайма.
Локальные аккаунты, конфигурация, очереди синхронизации, снимки, архив ошибок,
тестовые стенды и рабочие отчёты в установщик не включаются.

`npm run privacy:check` в `app` проверяет исходные файлы рантайма. Перед упаковкой
эта проверка запускается автоматически; после упаковки проверяется настоящий
`app.asar`, включая текстовые файлы зависимостей. Проверка сайта запускается
автоматически в конце `npm run build` в `site-source`.

Проверки находят личные пути, известные старые идентификаторы демонстрационных
данных, личные почтовые адреса, закрытые ключи, сохранённые учётные данные и JWT
кроме публичного ключа с ролью `anon`. Найденные значения в отчёт не выводятся.
Публичный адрес репозитория обновлений и публичный ключ Supabase не являются
учётными данными владельца.

Изображения сверяются по SHA-256 с `tools/privacy-reviewed-media.json` и
проверяются на EXIF, XMP и IPTC. Новое или изменённое изображение останавливает
сборку до просмотра и обновления списка. Список не следует обновлять автоматически
в сборке: он подтверждает отдельную проверку содержимого. Игровые карты, иконки
и снимки интерфейса с вымышленными данными допускаются; личные фото, снимки
рабочего стола и настоящие аккаунты для демонстраций не используются.

Сайт удаляет устаревшие файлы в своём каталоге `bundle` только после успешной
записи новой сборки. На хостинг следует публиковать каталог `site` с удалением
файлов предыдущей сборки, которых больше нет в новом каталоге. Исходники,
рабочие отчёты и каталог `out` публиковать нельзя.

Проверки строк, метаданных и хешей не заменяют визуальный просмотр новых снимков
и проверку новых сетевых функций. Рабочие данные пользователя проверяются
отдельно: сборка не должна читать их для получения примеров или ресурсов.
