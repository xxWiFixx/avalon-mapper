# Управление

| Элемент | Назначение |
| --- | --- |
| Карта | Граф порталов, карточки локаций и маршруты. |
| Статистика | Личный фейм, урон группы и управление сессией. |
| Найти Авалон | Поиск по названию или первым буквам. |
| Моя зона | Центрирование графа на текущей локации. |
| Вписать | Отображение всего графа. |
| Настройки | Хоткеи, источник зоны, оверлеи и сохранение данных. |

## Маршруты

Начало и цель задаются в полях справа или через меню локации. Доступны поиск ближайшего выхода в мир и сопровождение маршрута поверх игры.

«Картинка маршрута» открывает предпросмотр. PNG содержит все переходы, полные названия, цвета зон и известные сроки закрытия. Копирование помещает изображение в буфер обмена; сохранение открывает системный диалог. Длинные пути продолжаются по колонкам.

## Поиск и ручной ввод

Повторное нажатие хоткея закрывает поиск. Enter выбирает локацию, Ctrl+Enter задаёт текущую зону. В режиме ручной записи портала одно число после названия означает минуты, два — часы и минуты: `couexa 35`, `couexa 1 15`. Вместимость выбирается отдельно.

## Оверлеи

- Карта: название, активности и параметры портала; положение и масштаб настраиваются.
- Фейм: игровой значок и личная сумма за сессию.
- Урон: участники группы, оружие, урон, DPS и доля общего урона.

Оверлей урона изменяет размер за углы. Замок блокирует перемещение и взаимодействие со списком. Меню папки переключает общий урон и последний бой.

Темы основного окна: «Авалон», «Уголь», «Пергамент». Оверлеи сохраняют тёмное оформление.
