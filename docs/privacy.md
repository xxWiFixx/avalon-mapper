# Чтение трафика и передача данных

Документ описывает ветку `main`. Возможности опубликованных установщиков указаны в выпусках.

## Управление захватом

Трафик используется для определения зоны в режиме «Из трафика», личного фейма и урона группы. На новой установке зона читается с экрана, фейм и урон выключены. При обновлении сохраняются прежние настройки статистики.

Во вкладке «Статистика» доступны отдельные переключатели фейма и урона и состояние захвата. «Отключить чтение трафика» выключает оба счётчика и переводит зону с трафика на экран, если выбран этот источник. При отсутствии включённых функций, использующих трафик, сокеты захвата закрываются. Пауза статистики сокеты не закрывает.

## Обработка пакетов

На Windows используется системный сырой сокет с правами администратора. Он получает IP-пакеты активных сетевых интерфейсов. Приложение отбирает UDP-пакеты с портом 5056 и разбирает события зон, персонажа, группы, фейма и урона. Остальные пакеты отбрасываются. Отбор происходит в приложении, поэтому захват на уровне Windows не ограничен процессом Albion Online.

Модуль захвата не изменяет и не отправляет игровые пакеты. Сырые пакеты не сохраняются на диск и не передаются на сервер совместных карт. Счётчики хранятся в памяти процесса.

## Другие данные

Отключение захвата трафика не является автономным режимом: сохраняются проверка обновлений на GitHub, загрузка изображений предметов с сервера Albion Online и выбранная синхронизация карт через Supabase. Вход через Discord необязателен для личной карты; запрашивается область доступа `identify`.

В совместные карты передаются зоны, параметры порталов и авторы записей. Статистика, журнал переходов и позиция персонажа не синхронизируются. Снимки зон в режиме «Из трафика» не создаются. Снимок подсказки портала по хоткею управляется отдельной настройкой. Диагностические снимки сохраняются локально только при включённой настройке.

Для хранения токена входа используется системное шифрование Windows. При недоступности шифрования токен остаётся только в памяти; после перезапуска требуется повторный вход. Старые открытые токены при загрузке шифруются или удаляются с диска. Карты и настройки находятся в `%APPDATA%/avalon-mapper`.
