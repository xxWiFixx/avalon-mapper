# Чтение трафика и передача данных

Документ описывает ветку `main`. Возможности опубликованных установщиков указаны в выпусках.

## Управление захватом

Трафик используется для определения зоны в режиме «Из трафика», личного фейма и урона группы. Режим «С экрана» не читает трафик для определения зоны; если включены счётчики фейма или урона, они используют его отдельно. На новой установке зона читается с экрана, фейм и урон выключены. При обновлении сохраняются прежние настройки статистики.

Во вкладке «Статистика» доступны отдельные переключатели фейма и урона и состояние захвата. «Отключить чтение трафика» выключает оба счётчика и переводит зону с трафика на экран, если выбран этот источник. При отсутствии включённых функций, использующих трафик, сокеты захвата закрываются. Пауза статистики сокеты не закрывает.

## Обработка пакетов

На Windows используется системный сырой сокет с правами администратора. Он получает IP-пакеты активных сетевых интерфейсов. Приложение отбирает UDP-пакеты с портом 5056 и разбирает события зон, персонажа, группы, фейма и урона. Остальные пакеты отбрасываются. Отбор происходит в приложении, поэтому захват на уровне Windows не ограничен процессом Albion Online.

Модуль захвата не изменяет и не отправляет игровые пакеты. Сырые пакеты не сохраняются на диск и не передаются на сервер совместных карт. Счётчики хранятся в памяти процесса.

## Другие данные

Отключение захвата трафика не является автономным режимом: сохраняются проверка обновлений на GitHub, загрузка изображений предметов с сервера Albion Online и синхронизация карт через Supabase. Для облачного хранения без Discord создаётся гостевой аккаунт; доступ к нему зависит от сохранённого на устройстве токена. Вход через Discord необязателен для личной карты; запрашивается область доступа `identify`.

Порталы с известным временем закрытия из личной карты (пара зон, размер, время закрытия, способ записи и имя автора) сохраняются также на сервере в гостевой или Discord-карте. В «Все карты» объединяются активные порталы из личных облачных карт; имя автора там не выдаётся. Бесплатные аккаунты пополняют объединённую карту по умолчанию. Подписчик может отключить публикацию: уже записанные порталы перестают показываться в объединённой карте, но остаются в его личной облачной карте. Читать «Все карты» могут только подписчики; право проверяется сервером. В картах друзей авторы доступны участникам соответствующей карты.

Статистика, журнал переходов, положение персонажа и снимки экрана на сервер карт не передаются. Снимки зон в режиме «Из трафика» не создаются. Снимок подсказки портала по хоткею управляется отдельной настройкой. Диагностические снимки сохраняются локально только при включённой настройке. Владелец сервиса имеет административный доступ к личным картам, хранящимся на сервере.

Для хранения токена входа используется системное шифрование Windows. При недоступности шифрования токен остаётся только в памяти; после перезапуска требуется повторный вход. Старые открытые токены при загрузке шифруются или удаляются с диска. Карты и настройки находятся в `%APPDATA%/avalon-mapper`.
