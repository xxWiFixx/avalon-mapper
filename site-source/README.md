# Avalon Mapper website

`npm run build` updates `../site/`, including Russian and English pages. The existing local preview serves these files without restarting. `npm test` runs the cloud access, authentication, route adapter and stable placement checks. `npm run review:maps` serves an isolated fixture at `http://127.0.0.1:5196/map/`; fixture data is excluded from the production build.

The landing keeps its existing design and animations. One group server costs 799 RUB / 8.99 USD for 30 days and is activated or renewed by its owner with a FunPay code; members join free. The application and personal maps are free, with no personal paid plan or daily capture allowance. Hosted checkout is not used for code activation.

Upload only the contents of `site/` to an HTTPS host. Configure the site's HTTPS OAuth callback in Discord and Supabase before deployment. The hosting server serves static files and does not need Node.js or a local database. Build and review locally before publication.

The full-window web map takes its panel structure and Fira Sans fonts from the application, with the website's shared neutral dark palette and warm accent. Its colors are mapped to the landing's `--site-*` tokens in `src/cloud/maps.css`; saved desktop theme choices do not affect the website. `scripts/app-interface.js` runs when Vite loads and creates scoped styles and browser adapters in `src/cloud/generated/`. Do not edit those generated files. The router and activity formatting are derived from the actual application modules; static exports contain public game zones, activity icons, zone images and world adjacency, never player records.

Graph placement uses `app/ui/graph-layout.js` and `app/ui/stable-map-layout.js` directly. The `map_layout` RPC provides per-map coordinates and compare-and-swap revisions. New zones are placed incrementally, while timer changes preserve existing coordinates and the camera. A saved cloud layout is authoritative on reconnect; an explicit authorized reset is allowed to replace it. Group maps disable node dragging; personal-map dragging saves to the cloud. Missing RPC or offline access falls back to account-scoped browser coordinates with a 30-second retry delay. Signing out or losing map access clears private local placement entries and prevents late requests from repopulating them. The website exposes individual maps and servers, without a combined all-maps view.

The mobile interface switches between the graph, portal list and scrollable zone/route details. UI text and activity descriptions support both Russian and English. On desktop the graph fills the window behind the 308 px map list, floating zone card and independently collapsible route panel. The route panel can move below, left or right of the graph on wide screens, matching the application; on mobile the same controls remain in the details view.
