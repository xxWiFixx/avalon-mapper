# Безопасность

Сообщения об уязвимостях принимаются через [приватную форму GitHub](https://github.com/xxWiFixx/avalon-mapper/security/advisories/new). Для обычных ошибок используется [Issues](https://github.com/xxWiFixx/avalon-mapper/issues).

В сообщении указать версию приложения, версию Windows, условия воспроизведения и ожидаемое поведение. Не прикладывать токены входа, файл auth.json или полный сетевой захват. Сведения об уязвимости не публиковать в обычном issue до согласования исправления.

Исправления выпускаются для актуальной версии приложения. История изменений доступна в [Releases](https://github.com/xxWiFixx/avalon-mapper/releases). Проверка npm audit выполняется для изменений основной ветки; обновления зависимостей отслеживает Dependabot.

Приложение не требует отключать антивирус, SmartScreen или брандмауэр. Сетевой захват требует прав администратора и включается отдельными настройками. Его можно полностью отключить во вкладке «Статистика».

- [Обработка и передача данных](docs/privacy.md).
- [Проверка установщика](docs/verify-download.md).

Цифровая подпись издателя пока отсутствует. Проверка происхождения сборки GitHub не заменяет эту подпись, независимый аудит или проверку совместимости с правилами игры.
