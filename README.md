# Avalon Mapper

Приложение для Windows: карта Дорог Авалона, маршруты и статистика Albion Online.

[Скачать](https://github.com/xxWiFixx/avalon-mapper/releases/latest) · [Все выпуски](https://github.com/xxWiFixx/avalon-mapper/releases) · [Проверить установщик](docs/verify-download.md)

README описывает ветку `main`. Возможности установленных версий указаны в выпусках.

## Возможности

- Чтение названия, вместимости и времени закрытия портала с экрана по хоткею.
- Личная, совместные и объединённая карты; поиск зон по названию или уровню, маршруты и экспорт в PNG.
- Поиск ближайшей синей или жёлтой зоны, города либо Авалона с порталом в Бресилиен.
- Личный фейм, урон и DPS группы, отдельные оверлеи и журнал переходов.

## Использование

1. Выбрать источник текущей зоны в настройках.
2. Навести курсор на подсказку портала и нажать **F9**. Без прочитанного времени закрытия портал не сохраняется.
3. Выбрать начало и цель маршрута на карте. Кнопка «Картинка маршрута» копирует или сохраняет PNG.

**F10** открывает справочник всех Авалонов; повторное нажатие закрывает его. Кнопка «Найти Авалон» в приложении ищет только зоны открытой карты. Хоткеи меняются в настройках.

Оверлеи скрываются при сворачивании игры или переключении в другое окно. Для ручного скрытия всех оверлеев можно назначить отдельный хоткей, в том числе совпадающий с игровым хоткеем скрытия интерфейса.

## Источник текущей зоны

| Режим | Данные |
| --- | --- |
| С экрана | Изображение средствами Windows; для определения зоны трафик не читается. Область захвата настраивается. |
| Из трафика | События переходов; снимки названия зоны не создаются. После запуска нужен переход или ручной ввод. |
| Вручную | Текущая зона задаётся пользователем. |

Подсказка портала читается с экрана по хоткею при любом источнике зоны. Фейм и урон включаются отдельно; сетевой захват требует прав администратора. [Обработка данных](docs/privacy.md).

## Карты и хранение

Личная карта сохраняется на компьютере и в облаке без входа через Discord. Discord нужен для карт друзей и доступа к личной карте с другого устройства. Активные порталы по умолчанию пополняют «Все карты»; читать эту карту могут подписчики. Подписчик может отключить публикацию своих порталов.

Карты и настройки хранятся в `%APPDATA%/avalon-mapper`. Журнал и статистика на сервер карт не отправляются. Счётчики сбрасываются при перезапуске.
