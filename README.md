# Avalon Mapper

Приложение для Windows: карта Дорог Авалона, поиск маршрутов и статистика персонажа в Albion Online.

[Скачать последнюю версию](https://github.com/xxWiFixx/avalon-mapper/releases/latest) · [История выпусков](https://github.com/xxWiFixx/avalon-mapper/releases)

[Проверка установщика](docs/verify-download.md) · [Безопасность и сообщения об уязвимостях](SECURITY.md)

README описывает ветку `main`. Состав опубликованных сборок указан в выпусках.

## Возможности

- Распознавание названия, вместимости и времени закрытия портала по хоткею.
- Карты локаций, активности и поиск по названию или первым буквам.
- Маршруты через порталы и соседние зоны мира; экспорт в PNG и буфер обмена.
- Личные карты и совместные карты с доступом по ролям.
- Личный фейм за сессию и в час, урон и DPS участников группы.
- Отдельные оверлеи карты, фейма и урона; журнал переходов.

## Использование

1. Установить приложение из раздела Releases.
2. Выбрать источник зоны в настройках.
3. Навести курсор на подсказку портала и нажать хоткей фиксации.

По умолчанию: **F9** — фиксация портала, **F10** — поиск Авалона. Повторное нажатие закрывает поиск. Назначения меняются в разделе «Горячие клавиши».

Для передачи маршрута: **Найти путь → Картинка маршрута → Скопировать картинку / Сохранить PNG**.

## Определение зоны

| Источник | Работа |
| --- | --- |
| С экрана | Чтение полоски названия каждые 1,5–6 секунд. Область настраивается вручную. |
| Из трафика | События переходов игры. Снимки зоны отключены, включая резервное чтение при сбое. |
| Вручную | Указание зоны через Ctrl+Enter в окне поиска. |

В режиме «Из трафика» после запуска требуется переход в другую локацию или ручное указание зоны. Снимок подсказки портала по хоткею не зависит от источника зоны; он отключается настройкой «Снимок области у курсора».

Сетевой захват требует прав администратора. Они также могут требоваться для хоткеев поверх игры. При недоступном составе группы необходимо повторное вступление в группу.

Фейм и урон включаются отдельно во вкладке «Статистика»; на новой установке оба выключены. Кнопка «Отключить чтение трафика» выключает счётчики и при необходимости переводит определение зоны на экран. Пауза статистики захват не останавливает.

## Карты и данные

Личная карта работает без входа. Совместные карты требуют авторизации через Discord; создание и подключение по коду доступны кнопкой «+» в списке каналов.

Карты и настройки хранятся в `%APPDATA%/avalon-mapper`. Статистика хранится в памяти и сбрасывается при перезапуске.

В совместные карты передаются данные порталов и авторов записей. Позиция персонажа, журнал и статистика не синхронизируются. Диагностические снимки сохраняются только при включённой настройке; сырой сетевой трафик не записывается.

Распознавание зависит от видимости подсказки. Неподтверждённое время отмечается в интерфейсе. Статистика учитывает события, полученные клиентом игры. PNG маршрута содержит данные на момент создания.
