# Avalon Mapper

Приложение для Windows: карта Дорог Авалона, маршруты и статистика Albion Online.

[Скачать](https://github.com/xxWiFixx/avalon-mapper/releases/latest) · [Все выпуски](https://github.com/xxWiFixx/avalon-mapper/releases) · [Проверить установщик](docs/verify-download.md)

**Предрелиз для проверки:** [0.6.0-rc.1](https://github.com/xxWiFixx/avalon-mapper/releases/tag/v0.6.0-rc.1). Это кандидат на выпуск; стабильная версия по ссылке «Скачать» остаётся отдельно.

README описывает ветку `main`. Возможности установленных версий указаны в выпусках.

## Возможности

- Чтение названия, вместимости и времени закрытия портала с экрана по хоткею.
- Личная и совместные карты; поиск зон по названию или уровню, маршруты и экспорт в PNG.
- Поиск ближайшей синей или жёлтой зоны, города либо Авалона с порталом в Бресилиен.
- Личный фейм, урон и DPS группы, отдельные оверлеи и журнал переходов.
- Предупреждение об окончании еды с настраиваемым временем; восстановление игровых оверлеев после длительного простоя и сбоев окон.
- Управление серверами, ролями, приглашениями и банами; журнал добавления порталов с задержкой раскрытия автора 15 минут.
- Русский и английский интерфейсы: «Настройки → Прочее → Язык»; выбор сохраняется для всех окон.

## Использование

1. Выбрать источник текущей зоны в настройках.
2. Навести курсор на подсказку портала и нажать **F9**. Без прочитанного времени закрытия портал не сохраняется.
3. Выбрать начало и цель маршрута на карте. Кнопка «Картинка маршрута» копирует или сохраняет PNG.

**F10** открывает справочник всех Авалонов; повторное нажатие закрывает его. «Поиск зон на карте» ищет только зоны открытой карты, а «Справочник Авалонов» показывает справочные данные. Хоткеи меняются в настройках.

**F8** открывает ручной ввод портала: например, `couexa 1 15` — Coues-Exakrom с временем до закрытия 1 час 15 минут. Размер выбирается отдельно. Enter сохраняет портал, Ctrl+Enter задаёт текущую зону, F8 или Esc закрывает форму. Автоматическая и ручная запись бесплатны и не ограничены.

Владелец создаёт сервер для друзей через «+» слева с кодом активации на 30 дней. Продление доступно в «Мои сервера» и через ПКМ по серверу → «Подписка». Участники подключаются по приглашению бесплатно. Актуальная стоимость указана на сайте и в предложении продавца кода.

Оверлеи скрываются при сворачивании игры или переключении в другое окно. Для ручного скрытия всех оверлеев можно назначить отдельный хоткей, в том числе совпадающий с игровым хоткеем скрытия интерфейса.

## Источник текущей зоны

| Режим | Данные |
| --- | --- |
| С экрана | Изображение средствами Windows; для определения зоны трафик не читается. Область захвата настраивается. |
| Из трафика | События переходов; снимки названия зоны не создаются. После запуска нужен переход или ручной ввод. |

Подсказка портала читается с экрана по хоткею при любом источнике зоны. Фейм и урон включаются отдельно; сетевой захват требует прав администратора. [Обработка данных](docs/privacy.md).

## Карты и хранение

Личная карта сохраняется на компьютере и в закрытом облаке своего аккаунта. Discord нужен для серверов друзей и доступа к личной карте с другого устройства. Отправку порталов на каждый сервер выбирает пользователь в «Куда сохранять портал»; карту сервера видят только его участники с соответствующими правами.

Карты и настройки хранятся в `%APPDATA%/avalon-mapper`. Журнал и статистика на сервер карт не отправляются. Счётчики сбрасываются при перезапуске.
